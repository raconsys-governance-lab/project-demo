# Team Responsibilities

## Developers

Responsibilities:

- Feature development
- Bug fixes
- Pull Request creation
- Code review participation

---

## QA Team

Responsibilities:

- Test execution
- Regression testing
- Stage validation
- Release sign-off

---

## Production Approvers

Responsibilities:

- Production approval
- Release verification
- Risk assessment

---

## Administrators

Responsibilities:

- Repository governance
- Branch protection
- Team management
- Security configuration

---

## Escalation Flow

Developer
↓
QA
↓
Production Approver
↓
Administrator
